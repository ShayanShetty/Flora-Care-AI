# 🌿 Flora Care AI

Flora Care AI is an intelligent plant disease detection system that uses Artificial Intelligence to identify plant diseases from leaf images. It helps farmers, gardeners, and plant enthusiasts detect diseases early and take proper action.

---

## 🚀 Features

- 🌱 AI-based plant disease detection  
- 📸 Upload leaf images for analysis  
- 🔍 Accurate disease prediction  
- 👤 User authentication system  
- 💻 Full-stack web application  
- 🌐 Simple and user-friendly interface  

---

## 🛠️ Technologies Used

- Frontend: HTML, CSS, TypeScript  
- Backend: Node.js  
- AI/ML: Image processing model  
- Platform: Replit, GitHub
